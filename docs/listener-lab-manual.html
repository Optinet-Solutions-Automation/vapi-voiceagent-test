1. What is the Listener Lab?

The Listener Lab is a new way to train an AI voice agent. Instead of writing one enormous prompt that tries to cover every situation, you give the agent a short personality and let a smart backend “listener” feed it the right words at the right moment — live, during the call.

The idea: a politician and their staff

Picture a politician at a press conference. They have the charisma, the voice, and the delivery — but they don’t personally know every fact. Behind the scenes, a team listens to each question, finds the answer, and feeds it through an earpiece. The politician simply delivers it, smoothly and on-brand.

  • The agent is the politician — it carries only a short prompt describing its personality and delivery. It holds no product facts, prices, or policies.
  • The Playbook is the staff’s knowledge — a library of Scenarios, each with the exact line or briefing to use for a given situation.
  • The Listener is the earpiece — it follows the live conversation, recognises what the customer is really asking, and feeds the agent the right answer in real time.

Why this beats one long prompt

  • Consistency & compliance — critical lines (prices, terms, legal wording) are spoken exactly as written, every time.
  • Easy to tune — you edit one small Scenario, not paragraph 14 of a 3,000-word prompt.
  • Faster, smarter responses — answers are pre-defined and delivered the moment they’re needed.
  • Safe to experiment — everything happens in the lab; your live agents are never touched until you decide a setup is ready.

2. The Building Blocks

Four ideas, from smallest to largest. Each builds on the one before it:

TermWhat it is
ScenarioThe core unit. One situation the agent may face + the line to say + how to deliver it. (e.g. “customer asks about pricing”).
TagA category label on a Scenario, for organising and filtering — e.g. Promotions Q&A. A Scenario can have several.
PlaybookYour whole library of Scenarios.
CollectionA named bundle of Scenarios chosen for one campaign. Setting a Collection “active” narrows the agent to just those Scenarios.
ScriptA visual call-flow that orders Scenarios into steps with branching — built on the canvas (Section 8).
Also good to knowMeaning
Listener / RouterThe backend that hears each customer utterance and decides which Scenario it matches.
IntentThe meaning behind what the customer said.
DeliveryHow a line reaches the customer: verbatim (word-for-word) or reword (rephrased naturally).
InjectionThe moment the Listener feeds a line into the live call.

4. Configuration

Open Configuration, fill it in once, and press Save Configuration — a single button that saves your settings, applies the prompt & voice, and prepares the agent for the lab.

FieldWhat it does
AssistantWhich voice agent the lab controls. Use a dedicated test agent — saving overwrites its tools and settings.
VoiceThe voice the agent speaks with.
Short Behaviour PromptThe agent’s entire personality — tone, pacing, how to treat briefings. Deliberately short: how to speak, never what. Knowledge lives in the Playbook.
Webhook Server URLWhere the live call sends events. Pre-set on the hosted site — leave blank.
Router ModelThe AI that classifies each utterance.
Confidence ThresholdHow sure the Listener must be before feeding a line. Below it, the agent handles the moment alone. (Suggested 0.70)
Injection CooldownMinimum gap between two whispers, so the staff doesn’t interrupt constantly. (Suggested 4000 ms)
Trigger immediate responseOn = agent speaks the instant a line arrives; Off = it weaves the line into its next natural turn (gentler).

5. The Playbook & Scenarios

This is the heart of training. Each Scenario describes one situation and what the agent should do. Use the search box and the tag filter to find them; + Add Scenario to create one.

FieldWhat it means
NameA friendly label, e.g. “Wagering Requirements”.
Intent KeyA unique machine ID, e.g. wagering_requirements.
TagsOne or more category labels (Promotions, Q&A…). Type and press Enter, or click a suggestion.
Match GuidanceThe most important field. Describes when this Scenario should fire — the ways a customer might phrase it. The Listener reads this to decide matches.
ResponseEither the exact line to speak (verbatim) or a briefing to rephrase (reword).
Deliveryverbatim for facts/prices/compliance; reword for soft, conversational moments.
Actionanswer, give_offer, send_sms, end_call, or ignore.
ModeWhere it’s active: tool (only when the agent asks), listener (proactive push), or both.
PriorityTie-breaker when situations overlap — lower number wins. Keep compliance at 1–9, offer flow 10–19, Q&A 20+.

Verbatim vs. Reword

Use verbatim when exact words matter: prices, terms, legal lines, the offer, goodbyes — spoken precisely as written, every time.

Use reword when the moment is conversational: reassurance, soft objections — the agent rephrases the briefing in its own warm voice.

6. Collections (per-campaign bundles)

A Collection is a named set of Scenarios assembled for one campaign — e.g. “Lucky7 AU Reactivation”. It lets you reuse the same Scenarios across campaigns while running only the ones a given campaign needs.

ActionHow
CreateType a name and click + Create.
Choose its ScenariosClick Edit scenarios and tick the ones this campaign uses, then Save.
Set ActiveClick Set active. While a Collection is active, the Listener only considers its Scenarios — tighter, faster, no cross-campaign bleed. Clear returns to all Scenarios.
Rename / DeleteEdit the name inline; the trash icon removes the bundle (the Scenarios themselves are kept).

The active Collection is shown on the main page so you always know the scope of a test call.

7. Running a Test Call

  1. (Optional) Type a Client Name — the agent greets them by name.
  2. Click Start Call, allow the microphone, and speak as the customer.
  3. Watch the Listener Monitor update live; click End Call when done.

Reading the Listener Monitor

EventMeaning
heardWhat the customer said (final transcript).
classifiedThe matched intent and confidence score.
injectedA line was fed to the agent — with the response time in milliseconds. Flow steps show as flow:<type>.
skippedNo line fed, with the reason (low confidence, small talk, or cooldown).
tool call / resultThe agent asked for knowledge itself and received it.

The average response time badge is the key measure of whether the experience feels natural. In Logs, each past run shows its full transcript next to its listener timeline.

8. The Script Builder (call flows)

Scenarios are reactive — they fire whenever the customer triggers them. A Script adds a proactive spine: a visual flow that walks the call through ordered steps — intro → offer → ask for SMS → close — while Scenarios still answer anything off-script.

Open Script Builder for a full-screen canvas, much like an automation workflow tool. The canvas has a dotted grid; drag a box from the left palette onto it (boxes snap to the grid), then connect them by dragging from one box’s bottom dot to another’s top dot.

The boxes

BoxWhat it does
StartThe entry point. Choose Agent speaks first or Wait for the customer to speak.
SaySpeaks a Scenario’s line, then waits for the reply. The main box.
BranchSplits the path based on the customer’s reply (draw several arrows out, one per outcome).
Send SMSFires the text.
Set VariableStores a value (e.g. consent = true).
Transfer to HumanHands the call to a person (phone number).
End CallWraps up, optionally with a goodbye Scenario.

The arrows (conditions)

Click any arrow to set when it’s taken:

  • Always — move straight on.
  • If intent is… — branch on what the customer meant (e.g. agreed → SMS).
  • If reply is tagged… — branch by tag.
  • Otherwise — the fallback path so the flow never dead-ends.

Say and Branch boxes can also scope which tags are active at that step — narrowing what the agent will entertain mid-flow.

Multiple scenarios at one box

A Say or Branch box can hold more than one Scenario, in two ways that combine:

  • Candidate scenarios — add several lines under “Also consider”; when the flow reaches the box, the router speaks whichever candidate best matches what the customer just said (falling back to the primary). Great for offer variants.
  • Tag scope — allow any Scenario carrying a given tag to fire at that step.

A simple flow

Start → Greeting → Give Offer → ( Branch ) agreed → Send SMS → Close declined → Objection → Close question → (answered reactively, returns)

Making it run

  1. Build the flow, click Save.
  2. Click Set active — that script now drives your test calls.
  3. Start a call: the flow advances step-by-step on each reply, while off-script questions are still answered by the matching Scenario, then control returns to the flow.

Tip: Collections decide which Scenarios a campaign can use; a Script decides the order they flow in. Use them together — an active Collection plus an active Script.

9. The Tuning Loop

Training is a cycle: test → observe → adjust → repeat. Edits apply on the next utterance — even mid-call.

If you notice…Do this
The agent gave a wrong or vague answerEdit that Scenario’s Response.
The Listener missed a situationImprove the Scenario’s Match Guidance, or add a new Scenario.
A line was reworded that needed to be exactSwitch its Delivery to verbatim.
It fires on things it shouldn’tRaise the Confidence Threshold or sharpen Match Guidance.
The agent talks over itselfTurn off Trigger immediate response.
A campaign should use fewer ScenariosPut them in a Collection and set it active.

10. Troubleshooting

SymptomLikely cause & fix
The agent can’t hear meCheck the microphone for the site and your system input level. Bluetooth headsets sometimes use a profile with no mic — switch to hands-free.
Monitor stays empty during a callThe agent isn’t configured. Open Configuration and press Save Configuration.
Classifications show errorsThe AI account behind the router is out of credit, or the model name is wrong. Top up or correct the Router Model.
The agent answered the wrong thingCheck the heard line. If the words are right but the intent is wrong, improve the Match Guidance.
A page errors on loadA one-time database setup step may be pending — contact your administrator.

Remember: nothing in the Listener Lab affects your live production agents. It is a safe sandbox for building and proving a setup before rollout.
